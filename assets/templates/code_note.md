## 按这个顺序做

1. 取得开源代码，确认本次采用版本，保留干净基线；没拿到就说明，不编代码树。
2. 创建 `reading/annotated` 分支，给核心代码块加中文注释，不重构、不改行为。
3. 生成 `code_tree.md`，在 `code_map.md` 说明关键文件各干什么、前后如何连接。
4. 先看 README / 最小例子 → 配置 → 输入处理 → 模型 → 输出，再看数据 → loss → 参数更新。
   每步讲清输入输出、关键 shape，以及可设断点的位置。
5. 将模块对应到论文章节、公式、算法框或图，在 PDF 中做同色批注，写入真实代码片段。
   规范见项目 `related_work/code_annotation_guide.md`；不能确认的对应就注明。
6. 给出适合初学者的阅读顺序、需补概念和一个最小练习；运行情况写复现报告。
